
# Especialização Cloud & DevOps - AWS ☁️

Este repositório centraliza o desenvolvimento técnico, laboratórios práticos e automações realizados durante o **Bootcamp GFT - Cloud & AWS na DIO**. O projeto foca na transição da infraestrutura física para a nuvem, utilizando conceitos de **Infraestrutura como Código (IaC)** e automação de processos.

## 🎯 Objetivo
Demonstrar a aplicação prática de arquiteturas escaláveis e seguras na **Amazon Web Services**, utilizando ferramentas de mercado para garantir a reprodutibilidade e eficiência operacional.

## 🛠️ Tecnologias e Ferramentas
*   **Provedor Cloud:** AWS (EC2, S3, RDS, Lambda, IAM, VPC).
*   **Infraestrutura como Código:** Terraform.
*   **Automação & Scripting:** Python (Boto3) e Selenium.
*   **Containers:** Docker.
*   **Versionamento:** Git e GitHub.

## 📂 Estrutura do Repositório
O repositório está organizado de forma a facilitar a navegação por módulos e desafios técnicos:

*   `01-Fundamentos/`: Conceitos básicos de Cloud Computing e modelos de serviço (IaaS, PaaS, SaaS).
*   `02-AWS-Services/`: Práticas reais com instâncias EC2, buckets S3 e bancos de dados RDS.
*   `03-Terraform-IaC/`: Provisionamento automatizado de infraestrutura.
*   `04-Security-Compliance/`: Implementação de políticas de IAM e boas práticas de segurança.

## 🚀 Destaques Técnicos
1.  **Reprodutibilidade:** Ambientes configurados via Terraform para evitar o "clique-a-clique" e garantir consistência.
2.  **Automação de Hardware:** Uso de código para gerenciar recursos físicos virtuais na nuvem.
3.  **Foco em Segurança:** Configuração rigorosa de grupos de segurança (Security Groups) e permissões de acesso.
